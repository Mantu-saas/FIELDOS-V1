# Claude working rules for FieldOS
Founder is non-technical, minimum budget, 20-person pilot in 30 days.
1. Personal sales OS, not employer SFA. 2. No manager dashboard, attendance, surveillance, background GPS.
3. Mobile-first PWA. 4. Free services for pilot. 5. Supabase Auth/Postgres/RLS.
6. Deterministic target/planning math. 7. AI optional/pluggable. 8. Never expose secrets.
9. Explain every step plainly. 10. Create actual files and tests. 11. Maintain CHANGELOG.md.
12. Never claim untested code works. 13. One milestone at a time. 14. No V1 expansion without founder approval.
15. End each task with: changed files, test steps, known issues, next step.
