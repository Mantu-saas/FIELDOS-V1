# FieldOS (brand: Swayam)

The personal operating system for Indian field salespeople.
Plan the day. Chase the right customers. Hit the target. Get home on time. Stay healthy.

**Status:** Milestone 0 (setup and planning). No app code yet.

## What this is
- Individual-first, mobile-first PWA. The salesperson owns their data.
- NOT employer SFA, CRM, attendance, HR, manager dashboard or surveillance.

## Stack
React + TypeScript + Vite | Supabase (Auth, Postgres, Row Level Security) | Cloudflare Pages (free static hosting) | Google Maps links for navigation (no paid API).
